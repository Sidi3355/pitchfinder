# Feature ideas (product critic)

One line per idea: user story, effort guess (S / M / L), status.

| Idea                                          | User story                                                                                                                                                                                                                                     | Effort | Status  |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | ------- |
| Directions per player from the pitch page     | As someone organising Thursday football, I want each journey row on the pitch page to open Citymapper or Google Maps directions from that player's area so that nobody has to retype where the pitch is.                                       | S      | idea    |
| Kick-off time drives the ranking              | As someone organising Thursday football, I want to set a kick-off time (default next Thursday at 19:00) so that unlit pitches drop out of the ranking after dusk and the estimates reflect an evening journey.                                 | M      | idea    |
| Nearest station on the pitch page             | As someone organising Thursday football, I want the pitch page to name the nearest station or bus stop so that I can describe the pitch in the chat as "the cage by Whitechapel station".                                                      | M      | idea    |
| Headcount against the format on the game page | As someone organising Thursday football, I want the game page to show the in count against the pitch format (7 of 10 for five-a-side) so that I know the moment it is worth booking.                                                           | M      | idea    |
| Compare the top three on one shareable page   | As someone organising Thursday football, I want one link that lays the top three pitches side by side with every player's journey time so that the group can vote instead of me choosing alone.                                                | M      | idea    |
| Add myself from my phone's location           | As someone organising Thursday football, I want a one-tap "use my location" option in the add-player form so that the group starts with me already placed.                                                                                     | S      | shipped |
| Game page carries the address and directions  | As someone organising Thursday football, I want the game page itself to show the pitch address and one-tap Google Maps, Apple Maps and Citymapper links so that on the night nobody has to tap through to the pitch page to find the place.    | S      | shipped |
| Next Thursday by default, no past dates       | As someone organising Thursday football, I want Plan a game to default to next Thursday at 19:00 and refuse a date that has already passed so that I create the link in one tap and never send the group a game that is already over.          | S      | shipped |
| Time change asks everyone to re-confirm       | As someone organising Thursday football, I want players to see "moved from 19:30 to 20:00" on the game page with a prompt to confirm they are still in so that a change of time does not silently carry over answers given for the old time.   | M      | shipped |
| Game link previews with pitch, date and time  | As someone organising Thursday football, I want the game link to unfurl in WhatsApp with the pitch name, day and kick-off time so that the group knows what the link is before opening it.                                                     | M      | shipped |
| Journey times for the group on the game page  | As someone organising Thursday football, I want the game page to show each player's estimated journey to the pitch from the group that picked it so that friends can say in or out without opening the pitch page.                             | M      | shipped |
| Ask for a first name at first sign-in         | As someone organising Thursday football, I want to be asked my name the first time I sign in so that the game page says "Organised by Sam" rather than the front half of my email address.                                                     | S      | shipped |
| Remove or rename an answer on the game page   | As someone organising Thursday football, I want to remove a duplicate or mistaken answer (the second "Tom") or fix a name from my organiser panel so that the headcount and the cost split are right before I book.                            | S      | idea    |
| Organiser sets the price per head             | As someone organising Thursday football, I want to type what each person pays when I plan the game so that the game page and the copied message show one figure instead of the operator's hourly rate beside my "£10 each".                    | S      | idea    |
| Same again next Thursday                      | As someone organising Thursday football, I want a one-tap "Same again next Thursday" on any past or cancelled game so that the weekly link keeps the pitch, time, notes and group without going back through the map.                          | S      | idea    |
| Friends add their own starting point          | As someone organising Thursday football, I want the group link to let each friend add where they are coming from on their own phone so that I stop typing everyone's area and the ranking is built from real home locations.                   | M      | idea    |
| Flag venues that may not be public            | As someone organising Thursday football, I want cages named after a residents' gym, a school or a private club to carry a "may not be open to the public" flag and rank below open pitches so that I never send eight people to a locked gate. | M      | idea    |
| Chase the maybes                              | As someone organising Thursday football, I want a one-tap message that lists who is in, who is maybe and who has not answered so that I can nudge the group on Wednesday without counting names myself.                                        | S      | idea    |

## Shipped outside this list

Add to calendar (.ics), copy a message for the group chat, cost split per head on the game page,
recent locations in the add-player form, saved groups, directions links (Google Maps, Apple Maps,
Citymapper), report a problem, and routed journey times (OSRM) with source tags.
