# Design critic, iteration 2, 11 Sep 2026

Basis: the iter2 screenshot set (21:10) and the build served until 21:28, measured with Playwright on the iPhone 13 profile (390 x 664 CSS px at 1x) and at 1280 x 800. dist was rebuilt three times while this review ran (21:28 index-DU7B9vk_.js, then index-DzNqvRKR.js and index-Dkl_hZ2b.js) with iteration 3 work (a More menu, a "Where is everyone coming from?" panel), so those builds were used only to cross-check screens that still match the screenshots pixel for pixel (game page, plan-a-game form, profile at /me, save behaviour); lines that rely on them say so.

P1: The mobile pitch drawer covers the screen but is not modal (pitch-drawer, mobile). It is a fixed 390 x 664 aside with role="dialog", z-index 40 and no aria-modal; after opening, focus stays on the card link underneath, three Tabs land on "Save pitch", "Powerleague Canary Wharf" and "Save pitch" in the list behind it (visibleOnTop false for all three), 16 covered controls stay reachable, the list is not aria-hidden, Close is 30 x 30 at (340, 20), and on close focus drops to body. A keyboard or screen-reader user is left operating a list they cannot see. [new]
P1: The organiser and signed-in screens were not captured (game-organiser, profile-signed-in, both). mobile-game-organiser.jpg is byte-identical to mobile-game-guest.jpg (md5 e243a889), mobile-profile-signed-in.jpg to mobile-profile-signed-out.jpg (96bb118c), and the desktop pairs likewise (691a52fb, 8c893906); the header reads "Sign in" and the game says "Organised by organiser". Half of the iteration's new surface is unreviewable from the set. [new]
P1: Saving from a card changes only a colour (home, both, signed in). One control, two contracts, and the card version is invisible to anyone who cannot see green. Confirmed on the 21:28 and later builds. [new]

Verdict: Better than iteration 1, because the phone no longer pans, the drawer and dialog fit and the loading, error and empty states exist, but the new mobile drawer is a sheet that keyboard focus walks straight through, saving from a card changes only a colour, and the game, plan and report surfaces were built to the same sub-44 px targets and faint focus the last review measured.
